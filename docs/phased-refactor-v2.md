## 选词重构：从随机权重到逐词复习日程

### 重构前的缺口

- 选择器把错误次数、距离上次测试的天数压成分数，再做 Softmax 随机抽样；缺乏明确到期时间和学习阶段。
- 当前“遗忘曲线”只用 `7 - error_count` 估算衰减速度，无法区分初学、稳定记忆和遗忘后重学。
- 连续正确计数用于降低错误数，却不能可靠表达跨天巩固；提示、纠正和短时重复可能被当作独立掌握。
- 智能选词不是默认，部分服务仍保留旧随机 SRS 队列；游戏复习与重复率限制相互冲突。

### 新策略

1. **逐词状态**：保存版本、学习/复习/重学阶段、下次到期时间、记忆稳定时长、难度、上次复习/独立复习时间、遗忘次数、复习次数、学习步骤和上次结果。
2. **到期优先**：到期重学 → 到期复习 → 新词 → 未到期补位。先选迫切需要复习的词；随机性只能打散同优先级，不能把到期词挤出去。
3. **结果分级**：首次无提示正确为独立回忆；提示、揭示或改错后完成为辅助回忆；真实失败为遗忘。未尝试不产生失败记录，跳过与错误分开。
4. **间隔更新**：独立回忆按实际间隔扩展稳定时长；辅助回忆保守安排；失败进入短期重学。刚刚刷过的词再次答对，不获得不合理的长期间隔增长。
5. **新旧兼容**：旧词由已有测试时间、错误数和连续正确初始化；异常时间、负值、重复词和已删除词有明确处理。
6. **可解释**：首页显示到期数量与下一步；每次选词可解释为“到期重学 / 到期复习 / 新词 / 提前练习”，支持固定时间的可重复测试。

首版采用可配置的启发式遗忘模型，并非经过本项目历史数据训练的 FSRS，也不把估计保持率宣传为测得的准确记忆概率。艾宾浩斯原则落实为早期及时复习、成功后逐步拉长间隔、遗忘后缩短间隔；具体参数后续用隔日与跨周回忆数据校准。

## 游戏实现约束

九格连线：独立答对 100、提示/纠正后完成 70、新连线 80、全盘 200；分数仅作为首版规则候选，必须带 rulesVersion。学习状态只看实际表现，不由分数直接推导。智能练习不受榜单重复率限制。

星词漫游：题目固定、角色自动前进；岩台翻越、低拱滑铲、裂隙喷气。首次错误保留输入并至少留 3 秒补答，总局计时独立截止；同题不重复播放长跌倒。连击提升表现，不缩短阅读时间。Canvas 用单独时钟与渲染层，DOM 使用真实输入，支持 IME、Enter 防重、后台暂停和减少动态。无合法语境时使用中文释义，不现场阻塞生成 AI 例句。

本批实现约束：

- 首次 React 提交记录 `vocab-app-ready`，启动不等待 `document.fonts.ready`、`window.load` 或装饰图片；此标记不能等同于已登录数据加载完毕或首题可作答。
- 经典测试保留发音准备失败时的重试门槛；图片与可选词典资料不会串行拖住发音队列，也不会为加速而把不可用发音当作已准备。
- 公共查词缓存不存个人选义；共享请求按消费者取消，失败短期缓存后可以重试。背景补全在等待后核对账号身份版本、最新词文本和选义，并在写入时限定原值，避免迟到请求覆盖更新。
- 按需模块加载失败显示明确错误、返回入口与“刷新页面重试”，不自动刷新并清空未保存输入，不把浏览器缓存的失败 import 包装为原地重试成功。
- 主包优化按全部静态依赖计算初始 JS，不以单纯移动到另一个立即加载的 chunk 充当削减。可执行 `node scripts/report-build.mjs dist` 生成入口依赖图、初始 CSS、全部 JS 和延后模块报告。

已完成的启动专项验证：7 项启动/本地图标测试通过；app/tests 定向类型检查通过。使用 gstack 独立浏览器页，在生产预览的 `?no-fonts=1` 场景阻断全部外部字体后，81 个本地图标 ligature 均正确渲染，关闭/退出/返回图标可见；同源图标 WOFF2 为 **24,588 字节**，仅请求一次。官方来源、Apache 2.0 许可证、SHA-256 和更新步骤保存在 `public/fonts/`。
