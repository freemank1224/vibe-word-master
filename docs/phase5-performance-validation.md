## 已集成的加载改动

### 词典与测验准备

`services/dictionaryLookupCache.ts` 为公共查词请求提供规范化 key、在途请求合并、有限容量缓存、成功/失败不同有效期、调用方取消及覆盖响应体读取的期限控制。一个消费者离开不会取消仍被其他消费者需要的共享请求；失败不永久锁死查词能力。

`services/dictionaryService.ts` 先使用可用的共享词条，缺失时在有界预算内获取外部资料；基础查词不再逐条翻译全部候选含义，完整词义选项由对应交互按需加载。词典可用性仍取决于真实线上来源，不能把超时回退解释成所有词都有可靠释义。

经典测验准备拆成独立队列：音频并发 4、提示图片并发 4、可选词典补全并发 2。已有中文释义或已选择词义的词跳过可选补查；图片和词典不阻塞音频队列。发音失败保留开始门槛、失败数量和重试操作，不通过忽略音频错误获得更快的“准备完成”。切换题组或离开时取消旧准备任务。

App 背景补全复用相同的“只补缺失”判断。异步结果返回后重新检查账号身份版本、当前词文本/语言和选义；线上写入限定原账号、原文本、原语言、未删除状态、选义和待写字段旧值，防止覆盖期间发生的用户编辑。历史空字符串与 null 均按缺失值兼容；字段白名单固定，用户文本通过 SDK 参数传值。失败不写永久占位释义，也不清空已有音频或资料。

### 启动与样式

- 删除运行时 Tailwind CDN 编译，使用本地 Tailwind 3.4、PostCSS 和构建 CSS；保留原主题、文本颜色、forms/typography/aspect-ratio，补齐代码实际使用的动画和透明度样式。
- React 首次提交移除启动遮罩并记录 `performance.mark('vocab-app-ready')`。字体、图片和 `window.load` 不再控制可见性；不保留原来的 25 秒资源等待和额外退出动画等待。
- 装饰字体采用异步样式表与 `display=swap`，使用系统字体回退；可用性不依赖装饰字体下载成功。
- Material Symbols 使用同源 WOFF2 子集并预加载；仅包含实际使用的 81 个图标，保留 `FILL=0..1`、`wght=400..600`、`opsz=24`、`GRAD=0`。关闭、退出等图标不依赖第三方字体域名。字体加载期间保留固定图标位置，避免 ligature 文本撑开布局。

### 功能与依赖拆包

普通测验、三个游戏、登录/密码流程、账号与管理面板、词库选择、排行榜和奖励弹窗等通过独立按需模块加载。每个功能有自身加载边界；失败时提供明确提示及返回操作。浏览器可能缓存失败的模块请求，因此恢复按钮明确要求用户“刷新页面重试”，并提醒先保存未保存输入；应用不自动刷新。

AI provider、本地拼写 provider 与仅特定词形需要的 lemma 表按实际使用加载。`LocalProvider` 的词典下载有共同超时预算和失败后重试能力。Vite 输出 manifest，供初始依赖和延后模块核对。App 的完整页面拆分和路由改造仍属于后续阶段。
