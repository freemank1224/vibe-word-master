## Desktop testing

The user confirmed this app targets desktop landscape screens with keyboard and mouse input. Use 1366×768, 1440×900, and 1920×1080 viewports for all visual acceptance tests. Capture viewport screenshots, not full-page screenshots. Verify keyboard entry, Enter submission, mouse clicks, focus retention/recovery, and simultaneous visibility of the game scene, question, and input. Mobile portrait layouts, virtual keyboards, and mobile adaptation are outside the current product scope and release gates. Preserve historical narrow-screen results as historical extra checks; do not relabel them as desktop validation.
